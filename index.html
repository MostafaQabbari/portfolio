// Case study ⚡ AI-Powered Claude API

AtlasPlanner

A full-stack travel planner that uses the Claude API (Anthropic) to generate smart, personalized trip itineraries — with live weather, local events, and booking links. Built on a polyglot microservices stack: Python, Java, TypeScript, and PostgreSQL.

// Overview

Built as a portfolio project targeting EU Blue Card roles in Germany, AtlasPlanner demonstrates a production-grade polyglot microservices architecture where each language earns its place.

Python orchestrates the AI and external APIs, Java owns auth and data persistence, React drives the experience — and FastAPI never touches the database directly, always proxying through Spring Boot to preserve data ownership boundaries.
